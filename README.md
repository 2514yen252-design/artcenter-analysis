사용 데이터 개요
데이터 출처: 공공데이터포털(data.go.kr) 및 예술의전당 공개 데이터

데이터 구성
공연 및 전시 안내: 예술의전당에서 열린 공연명, 장소, 장르, 기간 정보
대관 시설 이용 현황: 공연장별 대관 신청건수와 실제 승인건수 통계
회원수 현황: 연령대별/등급별(유료, 무료 등) 회원 분포 데이터

데이터 클렌징 및 전처리 내용
인코딩 교정: CSV 파일을 불러올 때 한글이 깨지는 현상이 발생하여, EUC-KR에서 UTF-8로 인코딩 형식을 통일하여 한글 깨짐 문제를 해결했습니다.
테이블 구조화: SQL 분석을 용이하게 하기 위해 한글로 된 긴 파일명을 performance, rental, members라는 영문 테이블명으로 변경하고, 첫 행을 헤더(제목 줄)로 지정했습니다.
데이터 타입 변환: 문자열로 인식된 '승인건수', '나이' 등의 컬럼을 숫자 형식(Integer/Float)으로 변환하여 계산이 가능하도록 조치했습니다.
텍스트 매칭: 서로 다른 테이블 간의 공연장 명칭(예: '콘서트홀'과 '예술의전당 콘서트홀')이 일치하지 않는 문제를 해결하기 위해 SQL의 LIKE 연산자를 활용하여 데이터를 결합(JOIN)했습니다.

차트 1. 공연장별 대관 승인율과 실제 공연 비중
차트 설명: 각 공연장별로 대관 경쟁률(승인율)과 실제로 무대에 올라간 공연 건수를 한눈에 비교한 이중 축 차트입니다.

인사이트: 콘서트홀과 리사이틀홀은 승인율이 각각 30.4%, 15.5%로 경쟁이 매우 치열한데도 실제 공연 건수는 가장 많았습니다. 이는 특정 인기 시설에 수요가 집중되는 '레드오션' 현상을 보여줍니다. 예술의전당의 메인 수익원이자 정체성이 이 두 곳에 집중되어 있다고 볼 수 있습니다. 반면, 인춘아트홀은 승인율이 높으면서도 공연 건수가 많아 신진 예술가들에게 기회를 주는 효율적인 공간임을 확인했습니다.

차트 2. 연령대별 회원 등급 분포
차트 설명: 관객을 연령대별로 나누고, 그 안에서 유료 회원과 무료 회원의 비중이 어떻게 다른지 분석한 누적 막대 차트입니다.

인사이트: 50대 이상 연령층이 전체 회원수도 많을 뿐만 아니라, 다른 연령대에 비해 유료 등급(골드, 블루) 가입 비중이 월등히 높았습니다. 이들이 예술의전당의 실질적인 로열티가 높은 핵심 관객층임을 알 수 있습니다.

차트 3. 월별 공연 개최 현황
차트 설명: 1월부터 12월까지 월평균 얼마나 많은 공연이 열리는지 시계열로 분석한 라인 차트입니다.

인사이트: 예술의전당은 계절이나 기온 같은 환경적 요인보다는 '가정의 달(5월)'이나 '연말 시즌(10~12월)' 같은 기획 이슈에 따라 공연이 집중되는 양상을 보입니다. 또한 매달꾸준히 공연이 많아 특정 시즌에만 반짝하는 축제형 공간이 아니라, 1년 365일 상시 가동되는 '국가 대표 문화예술 플랫폼'임과 연중 균형 잡힌 공연 배분으로 관객들에게 끊임없는 문화 향유 기회를 제공하고 있음을 입증합니다.
